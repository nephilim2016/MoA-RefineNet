Adaptive Multi-Task Mixture-of-Adapters for GPR-Based Infrastructure Inspection under Diverse Electromagnetic Interference Conditions

Official implementation of the paper:

Adaptive Multi-Task Mixture-of-Adapters for GPR-Based Infrastructure Inspection under Diverse Electromagnetic Interference Conditions

Overview

This repository provides the implementation of the proposed Mixture-of-Adapters (MoA) framework for multi-task Ground Penetrating Radar (GPR) clutter suppression under heterogeneous electromagnetic interference conditions.

The proposed framework is designed to suppress three representative types of electromagnetic interference:

Shallow metallic diffraction and clutter
Heterogeneous-medium scattering
Multiple scattering and electromagnetic shielding

The repository also includes the implementations used for the ablation studies reported in the paper.

Requirements

Python >= 3.10
TensorFlow >= 2.15
NumPy
SciPy
OpenCV
Matplotlib

GPU acceleration is recommended.

Training

The training pipeline follows the three-stage optimization strategy described in the paper.

Backbone pre-training
MoA routing optimization
Joint fine-tuning

Please refer to

training_func.py

for the corresponding implementation.

Inference

After training, the reconstruction results can be generated by

python display_results.py

Router visualization can be generated by

python visualize_router_weights.py
Notes

This repository provides the implementation of the proposed framework.

The synthetic datasets used in the paper were generated using the forward modeling strategy described in the manuscript. Since portions of the experimental datasets involve ongoing research projects and engineering collaborations, the datasets are not included in this repository.

Users may substitute their own GPR datasets following the same input format described in the paper.
